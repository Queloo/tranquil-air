# PROYECTO TRANQUIL-AIIR
Tranquil-aiir es un sistema de adquisición y visualización de señales cardíacas utilizando como base Raspberry Pi Pico.
## DESCRIPCIÓN
En el proyecto utilizamos un sensor AD8232 para capturar las señales eléctricas del corazón y una pantalla TFT ILI9488 para mostrar la señal ECG en tiempo real.
El objetivo de este trabajo es poder desarrollar un prototipo compacto y portátil para su uso sencillo y flexible.
## CARACTERÍSTICAS
- Captura de señal ECG mediante módulo AD8232.
- Procesamiento digital de la señal con Raspberry Pi Pico.
- Visualización en pantalla TFT ILI9341 de 320x480.
- Comunicación SPI entre microcontrolador y pantalla.
- Diseño de PCB personalizada.
- Alimentación mediante batería Li-Ion.
